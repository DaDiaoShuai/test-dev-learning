# 05 · 测试框架合成 + CI/CD（第 3 个月）

把接口和 UI 两个方向合成一个完整框架项目，这是简历上放最前面的产出。

## 学习清单

- [ ] 框架合成：接口 + UI 合到一个项目，统一配置、日志、报告
- [ ] 稳定性：失败重试、失败截图/trace、环境切换
- [ ] CI/CD：接入 GitHub Actions，提交即跑冒烟集
- [ ] Docker 基础：别人拉下来按 README 就能跑

## 产出

- [ ] 一个完整框架仓库（可独立成仓后在此放链接）

## 过关标准

框架换一台机器能按 README 跑通；CI 上每次提交自动跑冒烟集并出报告。
