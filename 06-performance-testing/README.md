# 06 · 性能测试（第 3 个月）

先概念，再工具：JMeter 会用会看，Locust 用 Python 写脚本做一次完整实战。

## 学习清单

- [ ] 核心概念：并发、TPS、响应时间、错误率、吞吐量
- [ ] 场景设计：怎么定并发数、 ramp-up、持续时间，测什么业务链路
- [ ] JMeter：编写脚本、参数化、聚合报告解读
- [ ] Locust：用 Python 给接口项目写压测脚本并执行
- [ ] 瓶颈定位：结合监控与报告判断瓶颈在哪、依据是什么

## 产出

- [ ] 一份性能测试报告：场景、数据、瓶颈结论

## 过关标准

性能报告能讲清“瓶颈在哪、依据是什么”，而不只是贴一张聚合报告截图。
