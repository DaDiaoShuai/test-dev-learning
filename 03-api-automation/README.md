# 03 · 接口自动化（第 2 个月）

先用 Postman 摸熟接口，再用 Requests + PyTest 做自动化。

## 学习清单

- [ ] Postman：请求、环境变量、断言、集合运行
- [ ] Requests：请求封装、session、鉴权处理
- [ ] PyTest：fixture、参数化、标记、断言
- [ ] 数据驱动：测试数据与用例分离（YAML / JSON / CSV）
- [ ] Allure 报告：生成并能读懂报告

## 产出

- [ ] 接口自动化小项目一个（公开 API 即可），一条命令跑完出报告

## 过关标准

项目能一条命令跑完并生成 Allure 报告；新增接口时按现有结构加用例，不改框架代码。
