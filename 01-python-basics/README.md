# 01 · Python 基础（第 1 个月）

从前端（JS）视角对照学 Python，重点补测试开发日常真正用到的部分。

## 学习清单

- [ ] 数据类型：list / dict / set / tuple、字符串处理
- [ ] 函数：参数、返回值、作用域、常用内置函数
- [ ] 类与面向对象：类、继承、封装，写得出带类的小程序
- [ ] 异常处理：try/except、自定义异常
- [ ] 文件与日志：读写文件、JSON/CSV、logging 日志
- [ ] 虚拟环境与 pip：venv、requirements.txt
- [ ] 常用库初探：os / sys / re / json / datetime

## 产出

- [ ] Python 小练习约 10 个
- [ ] 一个带类、异常处理和日志的 Python 小程序

## 过关标准

能独立写带类和日志的 Python 小程序；能说清 Python 与 JS 在类型、作用域、异步等方面的关键差异。
