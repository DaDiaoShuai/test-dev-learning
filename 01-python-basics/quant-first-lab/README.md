# 量化第一课 · 动手小实验：给 BTC 做一次行情判型

量化学习第一课的加餐练习，不是今晚 Python 补课的必做任务，有空再玩 10 分钟就行。

只用已经练过的技能：`requests` 发请求、取字段、算数、f-string 打印。不引入新概念，也不需要任何 API key。

## 它做什么

拉币安公开的 BTC 1h K 线（`data-api.binance.vision` 镜像，免 key），然后算三个第一课讲过的指标：

- **EMA10 / EMA30** — 看金叉 / 死叉，判断趋势方向
- **RSI14** — 看超买（>70）/ 超卖（<30）/ 中性区
- **布林带 (20, 2)** — 看价格在带内的位置，贴上轨偏高、贴下轨偏低

最后打印一张判型小抄，把同一个行情分别用趋势跟踪、均值回归、网格、突破/动量四种视角读一遍。

## 怎么跑

```bash
cd 01-python-basics/quant-first-lab
pip install -r requirements.txt   # 只装 requests，装过就跳过
python quant_first_lab.py
```

每次运行拉的都是实时数据，数字和任何快照都不一样，这是正常的。

## 输出怎么读（示例）

以 2026-10-22 下午 17:15 的一次快照为例：

- BTC 约 81,874，EMA 死叉约 5 小时前形成 → 趋势跟踪看偏空
- RSI 27.1 超卖、价格贴布林带下轨 → 均值回归看跌过头了，但真趋势里这是接飞刀，不能只看这一条就抄底
- 近 7 天 79,800–84,898 宽幅震荡 → 网格在区间没破之前可玩
- 突破 / 动量暂无信号 → 还没带量冲出区间

重点不是数字本身，是体会：**同一个行情，不同策略会给出完全相反的解读。** 先判行情类型，再选策略。
