# 量化第一课 · 动手小实验：给 BTC 做一次行情判型

量化学习第一课的加餐练习，不是今晚 Python 补课的必做任务，有空再玩 10 分钟就行。

只用已经练过的技能：`requests` 发请求、取字段、算数、f-string 打印。不引入新概念，也不需要任何 API key。

## 它做什么

拉币安公开的 BTC 1h K 线（`data-api.binance.vision` 镜像，免 key），然后算三个第一课讲过的指标：

- **EMA10 / EMA30** — 看金叉 / 死叉，判断趋势方向
- **RSI14** — 看超买（>70）/ 超卖（<30）/ 中性区
- **布林带 (20, 2)** — 看价格在带内的位置，贴上轨偏高、贴下轨偏低

最后打印一张判型小抄，把同一个行情分别用趋势跟踪、均值回归、网格、突破/动量四种视角读一遍。

## 怎么跑

```bash
cd 01-python-basics/quant-first-lab
pip install -r requirements.txt   # 只装 requests，装过就跳过
python quant_first_lab.py
```

每次运行拉的都是实时数据，数字和任何快照都不一样，这是正常的。

## 输出怎么读（示例）

以 2026-10-22 下午 17:15 的一次快照为例：

- BTC 约 81,874，EMA 死叉约 5 小时前形成 → 趋势跟踪看偏空
- RSI 27.1 超卖、价格贴布林带下轨 → 均值回归看跌过头了，但真趋势里这是接飞刀，不能只看这一条就抄底
- 近 7 天 79,800–84,898 宽幅震荡 → 网格在区间没破之前可玩
- 突破 / 动量暂无信号 → 还没带量冲出区间

重点不是数字本身，是体会：**同一个行情，不同策略会给出完全相反的解读。** 先判行情类型，再选策略。

## 加餐 2：回测这个最小策略（可选加餐）

判完型还不算数——第一课的规矩是**实盘前先回测**。`backtest_min_strategy.py` 就把上面的最小策略（EMA10/30 金叉买且 RSI<70、死叉或跌 4% 卖）搬到最近约 125 天的 BTC 1 小时历史 K 线上真跑一遍：信号收盘产生、下一根开盘成交（防未来函数），手续费单边 0.1%，全仓现货、不碰合约。同样只依赖 requests。

```bash
python backtest_min_strategy.py
```

它会输出四项回测指标——胜率、盈亏比、夏普比率、最大回撤，外加一组参数敏感性对比（把 EMA 参数 ±20% 和大幅改动各跑一遍），最后给出一句结论：策略到底稳不稳健。

首轮真实运行快照（2026-10-23，数据为 2026-06-20 至 10-23 共 3000 根 K 线，每次运行数据都会变）：

- 基准 EMA10/30：总收益 +3.9%，但同期买入不动是 +28.1% —— 折腾 54 笔，远远跑输躺着不动
- 胜率只有 22.2%，但盈亏比 4.13 —— 典型的趋势策略长相：十次错八次，靠少数大赚把钱挣回来
- 夏普 0.57（不到 1 的“还行”线），最大回撤 12.0%
- 参数只小改 ±20%（8/28、12/36），总收益就掉到 +0.1% 和 -0.9% —— 默认参数的盈利没有余量，这就是过拟合的风险长相

结论：这个最小策略在这段历史里**不成立**，回测的价值恰恰是让你在花真钱之前知道这件事。

## 加餐 3：同区间对照——网格 vs 趋势 vs 买入持有（可选加餐）

第二课讲了先判行情（regime）再选策略，这份回测就拿同一批数据验这句话：`backtest_grid_vs_trend.py` 在同一段 BTC 1h 历史（最近 3000 根）上同时跑三方——买入持有、加餐 2 的趋势策略、现货网格。口径统一：本金 10,000 USDT、单边手续费 0.1%、只做现货；趋势部分直接复用加餐 2 的函数，避免两份代码算出两个结果。

网格用币安现货网格同款的配对挂单逻辑，且**不用未来数据定区间**：上下界只取最开始 30 天的最高/最低价，切 20 格。一处简化如实声明：1h K 线内价格路径不可知，按阳线 开→低→高→收、阴线 开→高→低→收 近似。

```bash
python backtest_grid_vs_trend.py
```

真实运行快照（2026-10-24，数据为 2026-06-21 至 10-24 共 3000 根；窗口比加餐 2 的快照滑动了一天，所以趋势数字与加餐 2 的 +3.9% 略有出入，属正常，每次运行数据都会变）：

- 买入持有 **+25.8%**（64,276 → 约 80,900）——这 125 天本质是上行趋势行情
- 趋势策略 **+3.1%**：54 笔、胜率 22.2%、夏普 0.47、最大回撤 12.2%
- 网格 **+1.2%**：区间 57,800–65,799，57 个套利回合**全胜**、兑现 +120 USDT，夏普 1.56、最大回撤只有 0.9%
- 参数敏感性：定区间方式和格数换了 4 种组合，网格收益在 +0.6%～+6.7% 之间，结论不翻——都远远跑输持有；40 格时回合冲到 206 次收益反而最低（格距 0.3%，被双边 0.2% 手续费吃掉大半）

怎么读这组数字（这才是这份回测想教的）：

- 网格回合 100% 胜率不等于策略好：它的小胜是真的，但价格 8 月下旬彻底离开区间后网格只剩现金，相对持有少赚约 2,463 USDT 的**踏空成本**不体现在任何一笔亏损里
- 网格回撤小、夏普高，不是因为强，而是因为大部分时间不在场内——现金曲线当然平滑
- 趋势策略胜率只有两成却能跟住一段涨幅，靠的是盈亏比；但在这段行情里最优解仍是躺着不动
- 一句话：**谁赢取决于行情是什么类型，不是策略高级不高级**——这就是先判 regime 的实战注脚
