# 02 · 测试基础 + 后端基础（第 1 个月）

测试思维和后端基础一起补，这是从前端转测试开发最核心的差距区。

## 学习清单

### 测试基础
- [ ] 用例设计：等价类、边界值、场景法、判定表
- [ ] 缺陷生命周期：发现 → 提交 → 修复 → 回归 → 关闭
- [ ] 测试类型：冒烟 / 回归 / 集成 / 系统测试的区别
- [ ] 测试计划与测试报告的基本结构

### 后端基础
- [ ] HTTP/REST：方法、状态码、请求头、鉴权、JSON
- [ ] SQL：校验型查询（select / join / group by / 子查询）
- [ ] Linux：常用命令、看日志（grep / tail / less）

## 产出

- [ ] 一份完整的手写测试用例（针对一个真实功能）
- [ ] 约 20 道 SQL 校验练习

## 过关标准

能讲清一个功能怎么测；接口报错时知道从状态码、日志、数据库三个方向排查。
